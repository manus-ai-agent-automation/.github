## Troubleshooting Common Issues

Install issues? Restart the task with a narrower brief when the plan drifts off target.  
Performance problems? Split very large jobs into two or three smaller tasks to keep progress visible.  
License/activation? Check the account plan if tasks queue for a long time before starting.  
Compatibility? Re-upload source files if the workspace shows a missing attachment.  
Update failures? Read the step log before retrying, since it usually names the failing action.
